# 08: Naming glossary for the Parkour Motion Code (parkour, freerunning, tricking, gymnastics/trampoline)

Date: 2026-09-29. Desk research only, $0 spent. No repo file was modified except this note.

Purpose: give every naming term a precise, sourced definition in terms of PMC primitives (setup, contact sequence, airborne rotation, exit), so names can be parsed into PMCs and generated from them. Conflicts between communities or sources are recorded explicitly, never resolved silently. Where a definition is my inference from usage rather than a stated definition, it is marked **[inference]**. Where nothing was found, it says **not found**.

## 1. Owner priority: Inward, Counter, Unwind

### 1.1 Inward

**Category:** modifier (travel-direction modifier on a rotation base move).

**Stated definition.** PTM (search summary): *inward refers to a flip that rotates opposite to its direction of travel of the center of mass; e.g. Inward Front is a forward rotating flip while the center of mass translates backward.* PT move pages agree base by base:

| PT move | PT description |
|---|---|
| Inward Front | "A backwards traveling front tuck set off of both feet. This move is typically done off a ledge." |
| Inward Side | "Side Flip rotating opposite to the travel direction." |
| Inward Frisbee | "Frisbee rotating opposite to the direction of travel." |
| Inward Webster Side (alias Loser Side) | "Webster Side flip traveling opposite the direction of rotation." |
| Inward Webster Front (alias **Loser**) | "A backwards traveling Webster." |
| Inward Tunnel Flip | "A backwards traveling Tunnel Flip." (Tunnel Flip = "A forward traveling Side Flip") |
| Inward Aerial Twist | "A backwards traveling Aerial Twist. This move is typically done off a ledge." |
| Inward Back Handspring | "Forward-traveling Back Handspring." |
| Inward Macaco | "A forward traveling Macaco." |
| Inward Flyaway | "Backwards swing into a front tuck." (Flyaway = "A forward swing released into a back tuck", aliases Swing Gainer, Bar Gainer) |
| Wall Inward Front (alias Wall Loser) | "One step up a wall set into a front tuck." |
| Devil Drop (aliases Cat Belle, Cat Loser, Cat Front) | "An Inward Front set from Cat Hang position." |

**Precise PMC definition (stated + [inference] for the generalisation).** Keep the base move's somersault direction and reverse its canonical travel direction, where travel = horizontal centre-of-mass velocity at take-off measured relative to the chest-facing direction at take-off. For front, side, webster, frisbee and aerial-twist bases the canonical travel is *with* the rotation, so "inward" reduces to "rotation opposite to travel" (the PTM wording). For the Tunnel Flip, travel is along the rotation axis (forward), so "inward" simply means travel reversed (backward); this is why the general rule has to be "reverse the base's default travel", not only "rotation against travel" **[inference from the Tunnel case]**. In PMC v0 terms: `travel: against` for front/side/back bases, and `travel: backward` for the tunnel base, which the current `with/against/lateral` enum cannot express.

**Lexicalisation (important for a generator).** The back-rotating inward flip is always called **Gainer** ("A two foot jump set into a forward moving back tuck"), never "Inward Back": of 184 PT names containing "Inward", none is an "Inward Back" flip; the only back-rotating bases taking "Inward" are "Inward Back Handspring" (3 names) and "Inward Macaco". Front-rotating inward flips have the alias **Loser** in several families (see I-4). A generator must emit "Gainer" for back + against, and should know "Loser" as an alias.

**Composes:** yes. PT applies it to Front, Side, Webster, Tunnel, Frisbee, Aerial Twist, Double Aerial Twist, Flyaway, Back Handspring, Macaco, Dive Roll, and inside sets (Wall, Palm, Punch Wall, Castaway, Kip, Toe-On). FIG ToT26 has "Wall Inward Frontflip", "Wall inward Sideflip (360)" and "Inward Tsukahara" (undefined). Twists attach after it and are independent of it ("Inward Front Half", "Inward Flyaway Full", "Inward Webster Rudi"). Inward says nothing about twist direction.

**Community:** parkour/freerunning (PT, FIG). Tricking uses "Loser" / "Reverse" instead (see conflicts).

**Conflicts:**
- **I-1 (diving).** In diving, "Inward" (group 4) means "takes off with their back to the water and rotates forward"; "Reverse" (group 3) means "takes off facing forward and rotates backward" (WP-Diving). Diving defines both relative to the take-off facing, not to travel. Diving "Reverse" is the parkour Gainer.
- **I-2 (lexicalised misnomer).** PTM: what is called an "Inward Down Monkey" is really a front handspring pushing off a wall (a wall front handspring); rotation and travel go the same way, so it is not inward, and read literally the name would mean "Inward Wall Inward Back Handspring". PT still uses "Inward Down Monkey" as a unit in more than 20 names. A parser must treat "Inward Down Monkey" as one lexical element, not as Inward + Down Monkey.
- **I-3 (two senses in the dive-roll family).** PT "Inward 360 Dive Roll" (alias Inward Vortex) = "A diving Masterswipe, which forms the first 180 degrees, collapsed into a roll, completing the 360 degree twist"; LK calls it "a masterswing-ing variation of the 360 Dive Roll". Here "inward" marks a masterswing (other-leg, inside) twisting entry, not travel reversal. But PT "Inward Dive Roll" = "Running Gainer set into a laid out backwards rotation landing on both shoulders into a forward roll", which is the travel-reversal sense.
- **I-4 (synonyms and scope).** "Loser": TP tricking = "a webster [after] short steps backwards ... a loser is the opposite [of a gainer], a front flip while traveling backwards"; TP parkour = "A front flip where you move backwards"; WP-Flip = "A front flip that ends with the performer moving behind the starting position". PT uses "Loser" as an alias for the webster-take-off inward front (Inward Webster Front = "Loser"), wall inward fronts (Wall Inward Front = "Wall Loser", and the two-foot Punch Wall Inward Rudi = "Wall Loser One and a Half") and cat-hang inward fronts (Devil Drop = "Cat Loser"), but gives no Loser alias to the plain two-foot "Inward Front". PT also has one inconsistent alias: "Webster Precision" ("Webster landing to a precision landing", not inward) = "Loser Precision". FIG ToT spells it "Looser" (Looser Frontflip 2.5, Looser Sideflip 2.5, Looser Frontflip 180 2.9) and also has "Wall Inward Frontflip" (2.1), with no definition of either. TB lists "reverse Webster" among its tricks, and its "Reverse" prefix is "the act of walking backwards into a trick".
- **I-5 (tricking).** No inward flip modifier was found in TB, TP or LK apart from "Inward 360 Dive Roll". In tricking "inward/inside" normally qualifies kicks (inside crescent).

### 1.2 Counter

**Category:** modifier (twist-direction modifier).

**Stated definition (PT).** "Counter X" = a twist of X in the direction opposite to the natural twisting direction (the twist momentum) produced by the set. All 13 PT names containing "Counter":

| PT move (aliases) | PT description |
|---|---|
| Corkscrew Counter Full (Kroc, Corkscrew Anti-Full) | "Corkscrew set into a twist in the opposite direction." |
| Corkscrew Counter Double Full (Double Corkscrew Anti-Full, Double Kroc) / ... Triple Full (Triple Kroc) | "Double-twisting [Triple-twisting] Corkscrew Counter Full." |
| Corkscrew Counter Arabian (Corkscrew Anti-Half Front, Kroc Arabian) | "Corkscrew set into an opposite half twist into front tuck." |
| Corkscrew Counter Full-In Back-Out (Kroc-In Back-Out) | "Corkscrew Counter Full during the first rotation and back tuck on the second rotation." |
| Wall Corkscrew Counter Full, Caster Wall Corkscrew Counter Full, Corkscrew Counter Full Down Monkey | "An opposite twisting Wall Corkscrew", etc. |
| Gaet Pimp Counter Full (Gaet Pimp Kroc, Gaet Pimp Anti-Full) | "A Gaet Pimp performed with a full twist in the direction opposite to the move's natural twisting direction." |
| Double Leg Counter Half (Double Leg Anti-Half) | "Double Leg with a half-twist opposite the natural twisting direction." |
| Tsukahara Counter Full Dismount | "Round off into opposite-side full twist. For example, right-side round off into a left (counter clock-wise) twist. In Gymnastics, this is referred to as just Tsukahara Full Dismount." |
| One-Hand Down Monkey Counter Full | "One-Hand Down Monkey with a twist counter-momentum to the set." |
| Two-Step Wall Inward Roundoff Counter Full | "Two steps into Wall Inward Round Off into a counter-momentum full twist." |

**Precise PMC definition.** The reference direction is the longitudinal-axis angular momentum already present at take-off from the entry (round-off turn, cork J-step/leg wrap, pimp hand pivot, double-leg sweep, one-hand wall push). Counter = the airborne twist has the opposite sign to that entry momentum. In every one of the 13 PT uses the entry is asymmetric (it has a built-in turning direction); none applies "counter" to a symmetric two-foot back or front flip. **[inference]** Counter is therefore undefined, and should be rejected by a parser, on entries with no natural twist direction.

**Aliases:** "Anti-" (Anti-Full, Anti-Half) and **Kroc** (= Corkscrew Counter Full; Double Kroc, Triple Kroc).

**Composes:** over twist amounts (Half, Full, Double Full, Triple Full, Arabian = half into front) and over any entry with a natural direction; combines with phase markers (Kroc-In Back-Out).

**Difference from Unwind:** counter's reference is the *entry's* twist momentum; nothing airborne is undone. Unwind's reference is the *immediately preceding airborne twist*.

**Community:** parkour/freerunning (PT, FIG via "Kroc"). Not found as a twist modifier in tricking (TB, TP, LK).

**Conflicts:**
- **C-1 (gymnastics names the same move differently).** PT "Tsukahara Full Dismount" (alias Kasamatsu Dismount) = "Round off into same-side full twist ... In Gymnastics, this is called Kasamatsu Dismount where as Tsukahara Full Dismount twists counter-momentum to the Round Off." So PT's "Tsukahara Counter Full" = gymnastics' "Tsukahara Full", and PT's "Tsukahara Full" = gymnastics' "Kasamatsu". **Not verified in FIG text:** FIG-MAG vault tables give "Hdspr. sw. w. ¼ t. a. salto fwd. t. w. ½ t. or Tsuk. t. w. 1/1 t. (Kasamatsu)" (#119) and "Kasamatsu str. with ½ t. or Tsukahara str. w. 3/2 t." (#126), i.e. equal values, but never state a twist direction.
- **C-2 (FIG uses "counter" for somersaults).** ToT25/26 list "Swing Counter Sideflip" (2.8) and "Swing Counter Frontflip" (2.9), undefined. FIG-MAG uses "counter salto" for a salto against the swing ("Swing fwd. and counter salto fwd. straddled to hang", HB) and for consecutive opposite saltos on floor ("counter saltos (example Double salto bwd. 1/1 to salto fwd. 1/1)"). So in FIG usage "counter" can qualify the **somersault** direction relative to the swing or previous salto, not the twist. **[inference, unconfirmed]** "Swing Counter Frontflip" is a front flip released from the forward swing, i.e. PT's "Lache Front" ("Lache set into front tuck").
- **C-3 (FIG lists Kroc without defining it).** ToT26: Cork 2.3 / Kroc 2.4, Double Cork 3.3 / Double kroc 3.7, Triple Cork 5.4 / Triple kroc 6.0. Only PT's alias links Kroc to "Corkscrew Counter Full".
- **C-4 (tricking).** No counter twist found. LK's "Hawkeye" ("A hook kick done with the round-kicking leg going against the rotation of the base trick") is a kick against the rotation, not a twist.
- **C-5 (trampoline).** Twist direction is not part of skill identity: synchro partners "must start facing in the same direction. Twists do not need to be in the same direction" (FIG-TRA §3.3). No counter concept.

### 1.3 Unwind

**Category:** modifier (twist-direction modifier, sequential).

**Stated definition (PT).** "X Unwind Y" = after a twist X (named, or implied by the base), a further twist Y in the **opposite direction to the immediately preceding twist**.

| PT move (aliases) | PT description |
|---|---|
| Arabian Unwind Half (Arabian Unhalf) | "An Arabian with a half twist in one direction followed by a half twist in the opposite direction." |
| Back Full Unwind Full | "Back Full opened into a twist in the opposite direction." |
| 360 Dive Front Unwind Half (360 Dive Front Unhalf) | "A 360 Dive Front with a full twist in one direction followed by a half twist in the opposite direction." |
| Flyaway Full Unwind Full-Down (Flyaway Unfull-Down) | "Flyaway Full opened early into a full twist." |
| Dive Half Back Unwind Full-Down (Jonah Unfull-Down) | "Jonah into a full twist after the flip in the opposite direction." |
| Macaco Quarter Unwind Quarter (Macaco Unhalf) | "early quarter turn, then reversing direction with a quarter turn in the opposite direction when both legs are overhead." |
| Arabian Unwind Half Unwind Half (Arabian Unhalf Unhalf) | "Unwind Arabian followed by a half twist in the opposite direction." |
| Flyaway Full-In Unwind Half-Out | "Flyaway Full-In with an opposite half twist during the second rotation." |
| Stride 360 False Unwind Gyro | "False Unwind: a mid-air phase that visually mimics an unwind but is produced by opening to increase moment of inertia and modulate twist, rather than an opposite-direction twist." |

LK (tricking) agrees: "Arabian Unhalf-In Back-Out" (other name "Arabian Unwind-In Back-Out") = "An Arabian which unwinds back in the opposite direction + a backflip." FIG ToT25/26 "Scaling, Form": "Rotation Direction: Reversed twisting direction (e.g., unfull ...)" is an upscale applied to a table trick, not a separate table entry.

**Precise PMC definition.** A twist segment whose sign is opposite to the previous twist segment in the same airborne phase (or across somersaults, as in "Full-In Unwind Half-Out"). Chainable: each Unwind flips relative to the immediately preceding twist, so "Arabian Unwind Half Unwind Half" = +180, −180, +180.

**Composes:** yes, over any twist amount, with timing suffixes (-Down, -Out) and with the Un- prefix (Unhalf, Unfull).

**Community:** parkour/freerunning (PT, FIG) and tricking (LK).

**Conflicts:**
- **U-1 ("Un-X" aliases are not self-describing).** Gainer Half Unwind Half = "Gainer Unhalf" (half, then opposite half); Macaco Quarter Unwind Quarter = "Macaco Unhalf" (quarter, then opposite quarter); Flyaway Full Unwind Full-Down = "Flyaway Unfull-Down" (full, then opposite full); Dive Half Back Unwind Full-Down = "Jonah Unfull-Down" (half from the dive, then opposite full). The amount of the first twist cannot be recovered from an Un-X alias.
- **U-2 (implicit first twist).** "Dive Front Unwind Half" is described as "a half twist in one direction followed by a half twist in the opposite direction" although the name never states the first half, while "Gainer Half Unwind Half" does state it. A bare "Unwind Y" may or may not imply a preceding twist equal to Y.
- **U-3 (FIG scope).** FIG gives "unfull" only as an example of "reversed twisting direction". Whether that also covers counter twists is not stated (Kroc has its own table rows, which suggests not **[inference]**).
- **U-4 (false unwind).** PT separately names a visual unwind produced by opening the body without a direction reversal. A vision reader that measures only body facing could confuse the two.
- **U-5 (trampoline).** Direction is not recorded, so a trampoline "Half in half out" does not say whether the second half continues or unwinds.

## 2. Conventions a parser/generator needs (with sources)

1. **Inward** reverses the base's default travel and keeps its rotation; "Gainer" is the fixed name for back + reversed travel, "Loser" an alias for the webster-take-off inward front (§1.1).
2. **Counter** is relative to the entry's twist momentum and only exists for asymmetric entries; **Unwind** is relative to the previous airborne twist and chains (§1.2, §1.3).
3. **Twist words to degrees.** Half = 180, Full = 360, One-And-A-Half / Rudi = 540, Double Full = 720, etc. PT aliases confirm the equivalence: Webster Full = "Webster 360", Webster One And A Half Full = "Webster 540", Devil Drop Rudi = "Devil Drop 540", Wall Full = "Wall Flip 360", Wall Double Full = "Wall Flip 720", Gainer Full = "Gainer 360". FIG writes degrees plus the count: "Backflip 720 (2 twist)", "Gainer 1080 (3 twist)".
4. **Position of a number encodes the phase.** A degree before an entry element is twist during that element: PT "360 Dive Kong" = "A full twisting dive into Kong vault"; "540 Dive Front" (alias Filipino). A degree after a flip is twist in the flip: "Wall Spin 540" = "Wall Spin into a 540 twist"; "Dash 360" = "Dash Vault into a 360 twist off the obstacle". FIG keeps both as different tricks: "360 Kong Gainer" (5.0) vs "Kong Gainer 360" (5.1) in ToT25/26.
5. **"Double/Triple" binds to the nearest rotation head.** With a flip head it counts somersaults (PT "Double Front Flip: A double rotating Front Flip", "Double Flyaway", "Double Palm Flip"). With a twist head it counts twists (Double Full, Double Cork, Double Kroc, Double Butterfly Twist; LK "Double Corkscrew: a Corkscrew with two rotations. Could be thought of as a double full off of one foot"). With a contact element it counts contacts or obstacles (PT "Double Kong: consecutive push-offs from two walls", "Double Dash Vault: Dash Vault off a vault into a Dash Vault off a consecutive obstacle"). "Double Leg" is a shape, not a count. Also, LK uses "rotation" for twists ("Double Full: A Full Twist with an extra rotation") while PT and FIG use "rotation" for somersaults ("double rotating"), so the word "rotation" alone is ambiguous.
6. **-In / -Out / -Mid.** FIG-TRA §L: "IN: the number of twists shown is performed in the first part of the element. OUT: ... in the last part. MIDDLE: ... in the middle part", used for multiple somersaults ("Half in rudy out FLIFFIS"). PT generalises this to named sub-skills and even contacts: "Corkscrew-In Back-Out: Corkscrew into a back tuck", "Flyaway-In Stall-Mid Back-Out: Triple Flyaway with a stalled second rotation", "Kong Front-In Punch Wall Flip-Out: Kong Front opened early to Punch Wall Flip", "Gaet Pimp-In Punch Wall Flip-Out: Double Gaet Pimp with a Punch Wall Flip on the second rotation". Tricking (TP "in/out") uses it within a single somersault too: "a double full twisting back flip with an x-out done in between the two full twists ... would be called a full-in X-Out full-out" (§4, P-2).
7. **-Up / -Down = twist before / after the somersault.** FIG form scaling: "Twisting Timing: Early or late twists (e.g., full-up or full-down)". PT: "Full-Up Side: 360 twist up while stalling the flip into a side tuck"; "Flyaway Full-Down: Flyaway into a full twist after the flip". LK: "Full Down: A Back Tuck with a late twist"; "Full Up: A Full Twist that stalls on the way up". Tricking "Gyro" is the same idea for kicks and twists ("a 360 degree twist ... performed after some portion of the trick & brings the performer into the landing", TP).
8. **Tricking kick numbers are not air rotation.** LK: "Due to the imperfect nature of mainstream terminology, the majority of rotation numbers assigned to the tricks do not reflect the accurate, in-air rotation of the actual trick." TP: Cheat 720 "still has 720 degrees of rotation from initial position to terminating position; however, only 540 degrees is performed in the air." LK's True Kick Terminology (TKT) renames them: Pop 360 = "Pop 180 Shuriken (TKT)", Cheat 720 = "Cheat 540 Hook (TKT)", Cheat 900 = "Cheat 720 Round (TKT)", Swing 900 = "Swing 720 Round (TKT)", Backside 720 = "Pop 360 Hook (TKT)", Backside 900 = "Pop 540 Round (TKT)". A parser must map kick names through a lookup per setup, not through arithmetic.
9. **"Double cork" means different things in different sports.** Tricking/FIG PK: one inverted-ish off-axis flip with 720 of twist (LK Double Corkscrew above; TP "A slant gainer with two twists before landing"; TP Gainer Double Full "Unlike a double cork, a double gainerfull must be completely inverted"). Snowboarding: "the naming convention is to first describe the horizontal rotation, followed by the number of off-axis rotations, terminated by the degree of total rotation (i.e. Backside Triple-Cork 1440)" (WP-Snowboarding). So "double cork 1080" = 2 off-axis inversions + 1080 total spin in snowsports.
10. **Landing leg is named relative to the spin direction, not left/right.** LK stances: Complete = "landing on the outside kicking leg (left leg if you spin left ...) in approximately Backside Stance"; Hyper = "landing on the inside kicking leg ... anywhere from Backside to Inside Stance"; Mega = outside kicking leg, "approximately Frontside"; Semi = inside kicking leg, "approximately Frontside"; Backside/Frontside = back/front facing the direction of movement; Turbo = both feet. Stances are suffixes: "a Corkscrew that lands in Hyper would be referred to as a 'Corkscrew Hyper'".

## 3. Glossary

Categories: **MOD** modifier, **PH** phase marker, **ROT** rotation base move, **CON** contact element, **DEG** degree convention, **STN** landing/take-off stance, **TRN** tricking transition, **POS** start position. Community: PK = parkour/freerunning, TR = tricking, GYM = artistic gymnastics, TRA = trampoline/tumbling, DIV = diving, SNOW = snow sports. "Composes" says whether the term applies productively to other bases.

### 3.1 Modifiers and phase markers

| Term | Cat | Definition in PMC primitives (quoted where possible) | Composes | Community | Sources | Conflicts |
|---|---|---|---|---|---|---|
| Inward | MOD | See §1.1. Reverse base's default travel, keep rotation. | Yes | PK | PT, PTM, ToT26 | I-1 to I-5 |
| Counter / Anti- / Kroc | MOD | See §1.2. Twist opposite the entry's twist momentum. | Yes (asymmetric entries only) | PK | PT, ToT26 | C-1 to C-5 |
| Unwind / Un-X | MOD | See §1.3. Twist opposite the preceding twist. | Yes, chainable | PK, TR | PT, LK, ToT25/26 | U-1 to U-5 |

## 7. Local data issues noticed (not fixed, reported only)

- `data/fig_tricks_2025.json` misreads the FIG table layout: several tricks printed on the same row are stored as aliases of each other. Examples: "Swing 180" aliases ["Kip"]; "Palm Backflip" aliases ["Palm SideFlip", "Ginger"]; "Cork" aliases ["Dark Arabian"]; "Wall Cork" aliases ["Gaet Pimp Backflip"]; "Triple Cork" aliases ["Tsukahara 360", "Double Frontflip"]; "Macaco-in" aliases ["Tsukahara", "Cartahara"]; "Tic Tac" aliases ["Lazy Vault", "Thief Vault"]; "Wallrun" aliases ["Arm Jump", "Underbar", "Tap Swing"]; "Wall Inward Frontflip" aliases ["Wall Inward Sideflip"].
